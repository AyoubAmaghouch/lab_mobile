# Prompt — Lab Markdown

Créer un document `markdown.md` en Markdown pour présenter le projet technique **Gestion des Véhicules V2**.

Le document doit présenter :

- **Sujet du projet :** Application web de gestion des véhicules permettant d'ajouter, consulter, modifier et supprimer des véhicules.
- **Objectif du projet :** Faciliter l'organisation et la gestion des informations des véhicules à travers une interface web.

Utiliser les éléments Markdown suivants :

- Titres et paragraphes.
- Texte en gras, italique et barré.
- Listes à puces et numérotées.
- Listes de tâches.
- Liens et images.
- Tableaux.
- Code et blocs de code.
- Citations et lignes horizontales.

Utiliser les technologies réelles du projet : HTML5, Tailwind CSS, JavaScript, PHP Native et JSON.

**Consigne :** Le document doit être clair, bien organisé, professionnel et contenir des exemples Markdown liés au projet Gestion des Véhicules V2.
