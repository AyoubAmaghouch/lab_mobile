# PROMT
Je veux que tu transformes le contenu de cours que je vais te fournir en une présentation professionnelle au format **Marp Markdown**, en respectant strictement les consignes suivantes.

### 1. Configuration Marp
- Utiliser Marp Markdown.
- Format 16:9.
- Activer la pagination.
- Utiliser le thème Default.
- Fournir un code Markdown complet, prêt à être utilisé dans un fichier `.md`.

### 2. Identité visuelle
Conserver le style graphique suivant :
- Fond rose : `#d8808a`.
- Texte rose clair : `#ffe0e3`.
- Diapositives claires : `#ffdde0`.
- Titres bleus sur les diapositives claires : `#2882f1`.
- Utiliser la police Anton pour les titres.
- Utiliser Arial, Helvetica ou sans-serif pour le contenu.
- Titres grands, gras visuellement et modernes.
- Design minimaliste, moderne et professionnel.
- Alterner entre diapositives roses et diapositives claires.

### 3. Organisation du contenu
- Créer une page de garde attractive.
- Ajouter un plan de présentation.
- Organiser le cours en sections et sous-sections.
- Présenter les notions progressivement.
- Utiliser des tableaux pour comparer les concepts.
- Ajouter des exemples pratiques et concrets.
- Décomposer les explications complexes sur plusieurs diapositives.
- Ajouter une diapositive « À retenir » après les notions importantes.
- Terminer par une conclusion et une diapositive de remerciement.

### 4. Lisibilité
- Ne pas surcharger les diapositives.
- Éviter les longs paragraphes.
- Utiliser des listes courtes et structurées.
- Respecter une hiérarchie claire entre les titres et le contenu.
- Adapter automatiquement la quantité de texte à chaque diapositive.
- Utiliser une taille de police confortable pour une présentation sur vidéoprojecteur.

### 5. Règles techniques importantes
- Utiliser uniquement la syntaxe Markdown compatible avec Marp.
- Utiliser `---` pour séparer les diapositives.
- Utiliser correctement les commentaires Marp, par exemple `<!-- _class: light -->`.
- Éviter les balises HTML inutiles.
- Ne jamais utiliser `<br>` pour organiser les titres.
- Ne pas ajouter de CSS ou de propriétés non nécessaires.
- Vérifier que toutes les diapositives respectent le format Marp.
- Corriger les erreurs de syntaxe avant de fournir le résultat.

### 6. Respect du contenu original
- Conserver toutes les informations importantes du cours fourni.
- Ne pas supprimer les notions, définitions, exemples ou méthodes.
- Ne pas inventer de nouvelles informations.
- Corriger uniquement les erreurs linguistiques et améliorer les formulations si nécessaire.
- Rédiger toute la présentation en français correct et professionnel.

### 7. Résultat attendu
Fournir uniquement le code Markdown complet, bien organisé, prêt à être copié dans Visual Studio Code et affiché avec l'extension Marp.
