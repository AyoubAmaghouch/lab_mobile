# Prompt de création du Lab

## 1. Contexte

Création d'un Lab d'introduction aux Labs et à la stack technique du projet technique **Gestion des Véhicules V2**.

Le projet consiste à développer une application web de gestion des véhicules permettant d'effectuer les opérations CRUD (Create, Read, Update, Delete).

L'application utilise une interface frontend développée avec HTML5, Tailwind CSS et JavaScript, un backend en PHP Native et un système de stockage des données au format JSON.

Ce Lab constitue une introduction à l'environnement technique, aux outils et aux méthodologies qui seront utilisés durant la réalisation du projet.

## 2. Objectifs

Permettre aux apprenants de :

- Comprendre le concept de Lab et son utilité pédagogique.
- Découvrir la stack technique du projet Gestion des Véhicules V2.
- Identifier les langages, frameworks et outils utilisés.
- Comprendre le rôle de chaque technologie dans l'application.
- Établir le lien entre les Labs et le projet technique final.
- Découvrir les 30 Labs organisés en quatre phases.
- Comprendre la progression pédagogique prévue pour les prochains Labs.

## 4. Décisions techniques

### 4.1 Format de présentation

- **Marp :** Création de présentations à partir de Markdown.
- **Markdown :** Rédaction simple et structurée.
- **Thème :** Thème par défaut avec une personnalisation minimaliste.
- **Git :** Gestion des versions et suivi des modifications.
- **Mermaid :** Création de diagrammes si nécessaire.

La présentation doit rester simple, lisible et professionnelle, avec un design minimaliste.

### 4.2 Stack technique du projet

#### Frontend

- **HTML5 :** Structure des pages web.
- **Tailwind CSS :** Mise en forme et création d'interfaces responsives.
- **JavaScript :** Interactivité et manipulation du DOM.

#### Backend

- **PHP Native :** Traitement des requêtes et logique métier.
- **API PHP :** Communication entre le frontend et le backend.
- **JSON :** Stockage et manipulation des données des véhicules.

#### Outils de développement

- **Visual Studio Code :** Environnement de développement.
- **Git :** Gestion de version.
- **GitHub :** Hébergement du code source et collaboration.

### 4.3 Architecture technique

L'architecture générale du projet est organisée comme suit :

**Frontend : HTML5 + Tailwind CSS + JavaScript**

↓

**Backend : API PHP Native**

↓

**Stockage : Fichiers JSON**

## 6. Méthodologie appliquée

### 6.1 Approche pédagogique

- **Progressive :** Apprentissage du simple vers le complexe.
- **Pratique :** Chaque Lab permet d'acquérir une compétence concrète.
- **Itérative :** Amélioration continue des connaissances et des réalisations.
- **Orientée projet :** Les connaissances acquises peuvent être mobilisées dans le projet technique.

### 6.2 Structure de chaque Lab

Chaque Lab peut comprendre :

- Une présentation du concept.
- Une documentation théorique.
- Des exercices pratiques.
- Des manipulations guidées.
- Un livrable concret.
- Des critères de validation.

### 6.3 Lien avec le projet technique

Les Labs permettent de développer progressivement les compétences nécessaires à la réalisation du projet Gestion des Véhicules V2.

Exemples de correspondances :

- **Lab Markdown :** Rédaction de la documentation du projet.
- **Lab Marp :** Création de présentations techniques.
- **Lab Tailwind CSS :** Conception de l'interface utilisateur.
- **Lab Preline :** Découverte de composants UI.
- **Lab OOP :** Organisation du code avec la programmation orientée objet.
- **Lab PHP Native :** Développement de la logique backend.
- **Lab ES7 JavaScript :** Amélioration du code frontend.
- **Lab Error JS :** Gestion des erreurs JavaScript.
- **Lab Issues (GitHub) :** Organisation des tâches et suivi des problèmes.
- **Lab Git :** Gestion des versions du projet.
- **Lab Planning :** Planification des étapes de développement.
- **Lab Lab Stack :** Compréhension de l'ensemble des technologies du projet.

Principe général :

**Lab → Apprentissage → Expérimentation → Compétence → Application dans le projet technique.**
